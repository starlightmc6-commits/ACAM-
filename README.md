# ACAM-
Aimitin collection of AI models. This is a project that aims towards native, CLI based open sourced AI models 

It is the very first project of Aimitin.
Aimitin tries to make privacy focused, lightweight and simple software. It also tries to fight against big tech and data collection.

ACAM is the Aimitin's collection of AI models 
It tries to create native runtime based, lighter and simpler AI models that don't harvest your data.
